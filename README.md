# GitHub Profile Card

Веб-приложение для поиска и просмотра профилей пользователей GitHub. Позволяет получить основную информацию о пользователе, а также просмотреть последние репозитории через публичный GitHub API.

## Что работает

* Поиск GitHub-пользователей по имени пользователя.
* Отображение аватара, имени, биографии и статистики профиля.
* Загрузка последних 5 репозиториев пользователя.
* Поиск по кнопке и по клавише Enter.
* Отображение индикатора загрузки во время выполнения запросов.
* Обработка ошибок при поиске несуществующих пользователей.

## Что не доделано

На данный момент реализованы все основные требования задания. Дополнительные функции (тёмная тема, история поиска, сортировка репозиториев и т.д.) не реализованы.

## Что я узнал во время работы

Во время выполнения проекта я научился работать с GitHub REST API и получать данные с помощью функции `fetch()`. Также разобрался с использованием `async/await` для обработки асинхронных запросов и преобразованием JSON-ответов в JavaScript-объекты.

Кроме того, я научился обрабатывать ошибки сервера, отображать сообщения пользователю и организовывать взаимодействие между HTML, CSS и JavaScript в небольшом веб-приложении.
