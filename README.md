# GitHub Profile Card

Приложение для просмотра GitHub-профилей.

## Возможности

- Поиск пользователей GitHub
- Просмотр статистики
- Просмотр последних репозиториев
- Обработка ошибок
- Индикатор загрузки

## Стек

- HTML
- CSS
- JavaScript
- GitHub API
